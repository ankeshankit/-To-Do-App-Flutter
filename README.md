# todo
This is a simple Todo app made with Flutter.


I created this app to learn and practice Flutter with SQLite. It is a simple Todo app where users can easily add , edite , update , delete and manage their daily tasks.

## Features

- Add Todo
- Edit Todo
- Delete Todo
- Check and Uncheck Todo
- Dark Mode
- SQLite local database

## Technologies Used

- Flutter
- Dart
- SQLite
- sqflite

## dependencies:
     flutter:
       sdk: flutter
     sqflite: ^2.4.3
     path: ^1.9.1
     path_provider: ^2.1.6

## Getting Started

This project is a starting point for a Flutter application.

1. Clone the project
git clone YOUR_GITHUB_REPOSITORY_URL
2. Open the project
cd todo
3. Install dependencies
flutter pub get
4. Run the application
flutter run


##How to Use
Add Todo
Click the + button.
Enter your Todo.
Click Add Todo.
Your Todo will appear in the list.


##Complete Todo

Click the circular checkbox next to a Todo.

##When checked:

The checkbox becomes selected.
The Todo text gets a line-through.
The completed status is saved in SQLite.
Update Todo

Click the edit icon ✏️ next to a Todo, modify the text, and click Update Todo.

Delete Todo

Click the delete icon 🗑️ to remove a Todo.

Dark Mode

Click the dark mode icon 🌙 in the AppBar to switch between light and dark mode.

💾 Database

The application uses SQLite for local storage.
